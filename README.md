# PrivaCV

**PrivaCV** 是一个用 Markdown + CSS 写简历的本地工具。你的简历内容不上传任何服务器，全部在浏览器里渲染、保存在浏览器本地存储里。

下载一个几 MB 的可执行文件，双击运行，断网也能用。

## 它解决什么问题

在线简历工具要么把你的手机号、公司名、薪资经历传到别人的服务器上，要么排版能力止步于「换个配色」。PrivaCV 的做法是：

- **内容用 Markdown 写** —— 专注写清楚做了什么、结果是什么，不用跟富文本编辑器搏斗。
- **排版用 CSS 控** —— 想调什么就调什么，字号、行距、分栏、页边距，全都是你的。
- **数据不出本机** —— 没有账号，没有后端接口，没有埋点。渲染发生在一个沙箱 iframe 里，前端依赖全部随二进制分发，运行时不请求任何外部域名。

## 特性

- **一份文件就是一份简历**：13 份内置模板，正文和排版写在同一份 Markdown 里（排版在开头的 `<style>` 块），拷到哪都长一个样。
- **实时预览**：按真实 A4 尺寸渲染，带分页线，能直接看出会印成几页。
- **导出 PDF**：走浏览器打印，矢量文字、可被 ATS 解析，不是截图。
- **本地库**：多份简历并存（投不同岗位改不同版本），带缩略图、复制、删除撤销。
- **导入导出**：单份导出 `.md`，全量备份导出 `.json`，换电脑或换浏览器时导回来。
- **快捷键**：`Ctrl/Cmd + S` 保存，`Ctrl/Cmd + P` 导出 PDF。
- **深色模式**：编辑界面跟随你的偏好，简历纸张永远是白的。

## 运行

**本地运行（推荐）**：到 [Releases](https://github.com/bapigso/PrivaCV/releases) 下载对应平台的二进制文件，运行后打开 <http://localhost:8080>。所有资源都嵌在这一个文件里，不需要联网。

**在线体验**：<https://bapigso.github.io/PrivaCV>（同样是纯前端，数据不离开你的浏览器，但如果你在意，还是建议用本地版本）

**从源码构建**：

```bash
go build -ldflags="-s -w" -o PrivaCV ./cmd/server
./PrivaCV
```

零外部依赖，`go.mod` 里只有标准库。

## 怎么写

### 基本结构

所有内置模板都认同一套结构，照着写就能直接换用任意模板的样式块：

```markdown
# 你的名字

一行联系方式 · 手机 · 邮箱 · 城市

## 工作经历

### 公司名 *2022.04 - 至今*
#### 职位 *城市*

- 用 STAR 写，把结果量化。
- 比如：接口 P95 从 620ms 降到 90ms，覆盖率从 31% 提到 78%。
```

关键约定：

| 写法 | 渲染成 |
|:--|:--|
| `#` | 姓名，页面顶部大标题 |
| `##` | 章节标题（工作经历 / 教育背景 / 技能…） |
| `###` | 条目主体（公司 / 学校 / 项目名） |
| `####` | 条目副标题（职位 / 专业 / 技术栈） |
| `*...*` | 斜体，模板把标题末尾的斜体浮到右边（用来放时间和地点） |

正文里不需要写任何 HTML。时间靠模板里一条 `h3 em { float: right }` 推到右边——想换个位置，改那一行就行。

Markdown 表格会按 GFM 语法解析，分隔行里的 `:--` / `--:` / `:-:` 分别表示左对齐 / 右对齐 / 居中；不写冒号就保持默认左对齐。GFM 要求表格必须有表头行，当它只是占位时留空、并在样式里写 `thead { display: none; }` 就不会印出来。

### 排版写在哪

排版全部写在文档开头的 `<style>` 块里，**没有第二个地方影响它**。改哪一行，哪里就变；想整份换个风格，就把那段 CSS 换掉。

预览时只额外注入两件事：纸张尺寸（A4、零边距）和打印分页约束（标题、列表项、表格行不被撕成两页）。这些是纸的物理属性，跟简历长什么样无关。

所以一份 `.md` 拷到任何地方、用任何 Markdown 渲染器打开，长相都一致——这也是「导出即原样」的意思。

### 分页

工具栏的「插入分页」会插入一个 `<div class="page-break"></div>`，从这里强制换页。标题、列表项、表格行默认不会被撕成两页。

### 双栏

想要侧边栏的话，用 `.cv-grid` 包起来（配合「校招 · 双栏一页」或「English · Sidebar」模板）：

```markdown
<div class="cv-grid">
<div class="sidebar">

## 联系方式
- ...

</div>
<div class="main">

## 工作经历
- ...

</div>
</div>
```

注意 `<div>` 开标签后面要空一行，否则 Markdown 解析器会把里面的内容当成原始 HTML。`.cv-grid` / `.sidebar` / `.main` 这几个类名由那两份模板自己的样式定义；换成别的模板它们就是普通 `<div>`，内容照常显示，只是不再分栏。

### 插入图片

工具栏的「插入图片」会把图片转成 Data URL 直接内嵌进 Markdown，不产生外链。代价是体积——浏览器本地存储通常只有 5MB 上限，超过 1MB 的图片会提示你压一下。

## 内置模板

每份模板都是一个自带 `<style>` 的完整 Markdown 文件：

| 模板 | 适用 |
|:--|:--|
| 后端工程师 | 社招技术岗，量化结果为主，一页密排 |
| 前端工程师 | 技能表格 + 项目经历，Typst 风留白 |
| 数据分析师 | 偏分析与实验方法论，指标口径写得清楚 |
| 产品经理 | 开头一句自我定位，经历按业务结果组织 |
| 技术负责人 / 总监 | 时间线走左侧列，履历节奏一眼看得出 |
| 财务 / 投资分析 | 教育背景前置、证书突出，偏书面的衬线排版 |
| 咨询 / 战略 | 案例按「问题 - 做法 - 影响」写，最正式的 LaTeX article 风 |
| 应届生 / 实习 | 教育 + 实习 + 项目 + 获奖，最保守的 ATS 排版 |
| 校招 · 双栏一页 | 全塞进一页的双栏版，演示 `.cv-grid` 写法 |
| Academic CV | 申博 / 教职 / 博后，含论文、教学、服务，天然多页 |
| English · Sidebar | 英文双栏侧栏版 |
| Frontend Engineer（2023 旧版） | 早期那份英文前端简历，青色标题、技能两列排 |
| Developer（2023 旧版） | 早期那份 LaTeX 风英文简历，Garamond 居中标题 |

想加模板不用改代码：把 `.md` 丢进 `web/content/`，然后在 `web/templates.json` 里加一条记录就行。

## 关于 ATS

不少公司用 ATS（简历筛选系统）先过一遍机器解析。如果你走的是海投或大厂官网渠道：

- 用「应届生 / 实习」这类单栏纯黑白模板，或至少保证单栏、无图片、无图标字体。
- 章节标题用「工作经历」「教育背景」这类标准叫法，别用「我的旅程」。
- 导出 PDF 时在浏览器打印设置里关掉页眉页脚，边距选「无」。

走内推或者猎头渠道时是真人看，可以放心用双栏和配色版本。这也是本地库支持存多份的原因。

## 数据存在哪

- 简历内容：浏览器 `localStorage`，key 是 `privacv.resumes.v3`。
- 界面偏好（深色模式、分栏比例、缩放）：`privacv.prefs.v1`。

都在你自己的浏览器里。清浏览器数据会一并清掉，所以重要的简历记得用「导出」做份备份。

从旧版本升级上来的数据（`resumeList`、`privacv.resumes.v2`）会自动迁移，样式原样内联进文档末尾，旧的 key 不会被删除。
