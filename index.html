我的简历

还没有简历。从下面挑一个模板开始，或者新建一份空白的。

模板

正文里还没有 <style> 块
使用帮助
它是怎么工作的

左边写一份 Markdown， 右边实时预览一张真实的 A4 纸，红色虚线是分页位置。 排版就写在同一份文档里的 <style> 块中——一份文件就是一份完整的简历，拷到哪都一样。 所有数据只存在这台设备的 localStorage 里，不经过任何服务器。

快捷键
Ctrl / ⌘ + S保存
Ctrl / ⌘ + P导出 PDF
Esc关闭对话框
拖动中间分隔条调整左右比例（也可以聚焦后用方向键）
约定：排版靠这几个标签认结构

所有模板都按同一套结构写，照着这个格式写就能直接换模板里的样式块，正文一个字都不用动 （工具栏「插入条目」会帮你写好骨架）：

# 姓名
一行联系方式

## 章节标题

### 公司 / 学校 *2021.06 - 至今*
#### 职位 / 专业 *城市*

- 用 STAR 法则写成果，尽量带数字

时间和地点写成 Markdown 斜体放在标题末尾，模板里一条 h3 em { float: right } 就把它推到右边——所以正文里不需要写任何 HTML。

改样式

一份 .md 就是一整份简历：排版全写在文档开头的 <style> 里，你看到的就是全部，没有别的地方在影响它。 直接改那段 CSS 就行，改哪里哪里变。

预览时只额外加两件事——纸张尺寸（A4）和打印时不要把标题、列表项、表格行撕成两页。 这是纸的物理约束，跟长相无关。

空白简历自带一份精简样式。如果你从别处导入的 .md 没有样式块， 点工具栏的「自定义样式」会在文末补一份完整的，照着改即可。 凑页数优先动 body 的 font-size 和 h2 的 margin，别去删内容。

分页

在需要断开的地方插入 <div class="page-break"></div>（工具栏「插入分页」按钮会帮你写）， 打印时就会从这里翻页。标题、列表项、表格行默认不会被撕成两页。

表格

GFM 的表格语法要求有表头行。当表头只是占位、不想印出来时，把它留空， 并在样式里写 thead { display: none; }（模板都是这么做的）：

|  |  |
|:--|:--|
| 语言 | 中文、英语 |
| 输出 | 技术博客 60+ 篇 |
双栏

「校招 · 双栏一页」和「English · Sidebar」两份模板的样式需要内容里有下面这样的容器，注意 <div> 后面要空一行， Markdown 才会继续解析。这两个类名由那两份模板自己的样式定义，换成别的模板就是普通的 <div>，内容照常显示：

<div class="cv-grid">
<div class="sidebar">

## 联系方式
- ...

</div>
<div class="main">

## 工作经历
...

</div>
</div>
ATS：投递前想一下

不少公司会先用简历筛选系统做机器解析，双栏、表格、文本框、图片里的文字都容易被读乱甚至丢掉。 投大厂、校招和猎头渠道建议用 应届生 / 实习 或 后端工程师 这类单栏模板； 双栏那两份留给人工渠道或者作品集。

导出 PDF

点「导出 PDF」会调用浏览器打印。在打印对话框里记得把页眉和页脚关掉、边距选「无」， 页面尺寸选 A4，否则会多出网址和页码。缩放保持 100%。

头像

点「插入图片」会把图片转成 Data URL 直接嵌进 Markdown，不会上传。注意浏览器本地存储通常只有 5MB 左右，图片建议先压到 200KB 以内。 位置和大小用 CSS 的 img 选择器调。

字体

中英混排建议无衬线：思源黑体、 San Francisco； 纯英文简历用衬线也很好。字体必须是本机装了的才会生效，导出 PDF 时会被嵌入。

写作

STAR 法则 · 中文文案排版指北 · 图标可以从 Feather Icons 复制 SVG 直接粘进来。

数据在哪

在浏览器的 localStorage 里。清浏览器数据、换浏览器、无痕模式都会丢， 所以请定期用「备份全部」导出一份 JSON。单份简历「导出」出来的 .md 就是文档本身，样式在里面，扔到别处也能原样渲染。
